## EarthSciASTDiff v0.6.2

A patch release. Every binding now accepts EarthSciAST 0.13 and 0.14, which
read esm 2.3.0, as well as 0.11 and 0.12. One fix: a faq observed whose
`output_idx` is absent in the typed AST. The derivative rules, the band
format and the goldens are unchanged from 0.6.1.

### New

- **EarthSciAST 0.13 and 0.14 are supported** (Julia
  `0.11, 0.12, 0.13, 0.14`, Rust `>=0.11, <0.15`, Python `>=0.11,<0.15`).
  The floor stays at 0.11. Upstream changes that matter here:
  - esm 2.2.0 applies the pointwise lift on every route that brings a grid
    to a 0-D system. In a coupled document on such a route, a state that
    used to be evaluated at one element becomes a per-cell array, so its
    flattened system, and therefore its Jacobian, is now per cell. This is
    EarthSciAST's flattening; the band calculus is unchanged.
  - esm 2.3.0 deprecates `neg` and `pow`, and the loader rewrites them to
    unary `-` and `^`. The rules for both spellings stay, since 0.11 and
    0.12 still pass them through. None of the derived documents emits
    either one.
  - EarthSciAST 0.14 removes the plain-text renderers (`to_ascii`, ...).
    No binding of this package used them outside one Julia test, which now
    compares serialized expressions.

### Fixed

- **A faq observed definition with `output_idx` absent** (`nothing` /
  `None`: the schema requires the field on the wire, the typed AST does
  not) is now read as `output_idx = []`, a scalar sum. In Julia and Python,
  the band calculus, the inliner and the indexed-definition rewrite read the
  field without allowing for an absent list, and a bare read spliced the
  definition with the field still absent. Rust already read an absent list
  as `[]` in those places. All three bindings now normalize the collected
  definition, so they splice the same tree whether the field is absent or
  empty.

### Conformance

- conformance.yml now tests every binding at EarthSciAST 0.11.0 and 0.14.0.
- The output_idx-absent test no longer passes by construction. It checks the
  collected definition, the inlined right-hand side and the Jacobian bands
  in all three bindings (Rust gains the test).
