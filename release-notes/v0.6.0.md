## EarthSciASTDiff v0.6.0

Every binding now requires EarthSciAST 0.11, which reads esm 2.0.0. The Julia
reference now differentiates through causal recurrences, as the Rust and
Python bindings already did, and it writes the recurrence goldens itself.
This is a breaking release: documents that use the `fn` closed functions,
`table_lookup` or the `aggregate` spelling no longer load, and EarthSciAST
0.10 and older are no longer supported.

### Breaking changes

- **EarthSciAST 0.11 is the floor in every binding** (Julia `0.11`, Rust
  `>=0.11, <0.12`, Python `>=0.11,<0.12`). esm 2.0.0 removed the `fn` closed
  functions (`datetime.*`, `interp.*`), `table_lookup` and the `aggregate`
  spelling of `faq`. The loader refuses a document that uses one
  (`removed_op`). Migrate such documents with EarthSciAST's codemod to the
  esm:std templates (`esm:std/calendar.esm`, `esm:std/interp.esm`).
- **The `fn` derivative table is removed** from every binding (spec §3.4).
  The esm:std templates expand into core operators at load, and the core
  rules differentiate them. They give the same derivatives as the old table:
  0 for the integer calendar fields and `searchsorted`, `d[t]/86400` for
  `julian_day`, and the active segment's slope for `linear` and `bilinear`.

### New

- **Julia: causal recurrences** (spec §4.5, §9.7; #3, #45). An observed that
  reads itself at an earlier cell is now an intermediate. It is
  differentiated on its definition and as an extra column of its readers,
  and the chain rule is composed through the line's transfer recurrence
  `T = (I − G)⁻¹`. New exports: `Recurrence`, `ExtendedBands`, `recurrences`,
  `extended_bands`, `transfer_definition`. The block's `auxiliary` field, the
  second-order `recurrences` field, the §9.7 tangent and adjoint sweeps of
  `jvp_document`, `vjp_document` and `hvp_document`, and the `column_block`
  plan's `diag_plus_rank1` pattern are all supported. The Julia reference
  refuses two active recurrences that read each other (`BandError`), where
  it would otherwise recurse without bound.
- **Derivative rule for `index` of a literal array** (spec §3.2). A read of
  a literal array that reads no variable is piecewise-constant in its
  integer subscripts, so its derivative is 0. The esm:std templates
  differentiate through this rule.
- **Non-finite coefficient literals** (spec §4). A simplified coefficient
  can fold to NaN or ±∞, for example in the calendar templates' `0/0`
  branch for `|t| ≥ 2⁵²` s. Every binding now writes NaN as `0/0` and ±∞ as
  `±1/0`, since JSON cannot hold them.

### Changed

- The CSE child slots no longer include `axes` (spec §4.1), because esm
  2.0.0 removed that field.

### Conformance

- `tests/valid/tgrad_photolysis.esm` is now an esm 2.0.0 document (migrated
  with the codemod). Its six `time` goldens are regenerated, and their values
  are unchanged.
- The Julia reference writes the goldens of `recurrence_sweep` and
  `pbl_rank1`, and the Rust golden writer
  (`pkg/earthsci-astdiff-rs/tests/write_goldens.rs`) is removed. Every
  structural golden is byte-identical. The two recurrence `*.hvals.json`
  files change in the last digit, because the pinned stage inputs differ by
  one ulp between Rust's libm and Julia's.
- Three more `*.hvals.json` goldens (`arrhenius_chem`, `filtered_scan`,
  `semiring_reduce`) change by at most 3e-15 relative under EarthSciAST
  0.11's evaluator.
- A new Rust test (`pkg/earthsci-astdiff-rs/tests/std_templates.rs`) checks
  the esm:std templates' derivatives against central differences of the
  source, evaluated by EarthSciAST.
