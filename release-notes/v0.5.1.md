## EarthSciASTDiff v0.5.1

A patch release. The Rust binding's `stable_json` now writes the same float
digits as the Julia reference in every case. The Julia and Python packages
behave exactly as in 0.5.0; their versions move with the crate's.

### Fixed

- **Rust: `stable_json` writes a decimal tie with the even last digit.** Some
  doubles lie exactly halfway between two shortest decimal strings that both
  read back as them (705129328097.90625 between `7.051293280979062e11` and
  `…063e11`). The Julia reference (`JSON3.write`, Ryu) and Python's `repr`
  write the even one; Rust took its digits from std's `{:e}`, which writes the
  upper one. Rust now takes its digits from Ryu (the `ryu` crate, already a
  dependency through serde_json) and keeps its layout code. On ReSEACT's
  chemistry operator the derived `rhs` and `jacobian` documents differed from
  Julia's in 1,674 numbers each; they are now byte-identical.
  EarthSciIntegrator should require `earthsci-astdiff >= 0.5.1`.

### Conformance

- New golden `tests/goldens/canonical_floats.json`: `[bits, text]` pairs that
  every binding's `stable_json` must reproduce, covering ties, powers of two
  where only one candidate reads back, the RFC 8785 Appendix B vectors,
  subnormals and the layout switches. `scripts/regenerate-goldens.jl` rewrites
  its texts from the bits. Spec §5 item 2 now states the tie rule.
