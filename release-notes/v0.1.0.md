## EarthSciASTDiff v0.1.0

First registered release. EarthSciASTDiff differentiates `.esm` expression ASTs
symbolically and emits the Jacobian as structured bands, with a Julia reference
implementation (this package) and Python and Rust bindings that are gated
against the same goldens.

This is a new package, so nothing here breaks an earlier release; the
"Breaking changes" entry below is a commit from before the first tag (the port
to EarthSciAST 0.1.x / esm 1.0.0), not a change for users.
